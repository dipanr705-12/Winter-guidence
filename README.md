## 🚀 Features
- **Responsive Design:** Optimized for mobile, tablet, and desktop views.
- **Modern UI/UX:** Clean, intuitive interface.
- **Durga Puja Pandals Directory:** Comprehensive West Bengal pandals guide with search, zone filters, transit routes, and Google Maps integration.
- **Netlify Integration:** Continuous deployment for real-time updates.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript
* **Deployment:** [Netlify](https://www.netlify.com/)

⚙️ Getting Started
Follow these steps to set up the project locally on your machine:
1. Prerequisites
Ensure you have a modern web browser installed (Chrome, Firefox, or Edge). If you want to contribute, ensure you have Git installed.
2. Installation
Clone the repository using the following command:
git clone [https://github.com/dipanr705-12/Winter-guidence.git](https://github.com/dipanr705-12/Winter-guidence.git)

3. Running the Project
 * Navigate into the project folder:
   cd Winter-guidence

 * Open the project:
   * Option A: Double-click the index.html file in your file explorer.
   * Option B (Recommended): If using VS Code, right-click index.html and select "Open with Live Server".
